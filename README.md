# Projeto Avalia (Monorepo)

Sistema completo de avaliação de eventos e geração de certificados.

## 🧠 Memória do Projeto
Este projeto utiliza um sistema de memória para o Antigravity (IA).
- **Log de Decisões**: `.agent/memory.md`
- **Importante**: Em novas sessões, peça ao Antigravity para ler o arquivo de memória para manter o contexto técnico.

## 📂 Estrutura
- `/frontend`: Aplicação Next.js 15+
- `/backend`: API Node.js/Express com Prisma 7 e SQLite

## 🚀 Como Iniciar
1. **Backend**: 
   ```bash
   cd backend
   npm install
   npm run dev
   ```
2. **Frontend**:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
